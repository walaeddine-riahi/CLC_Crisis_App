# CLC Crisis Decision Support

Application de soutien à la décision pour le **Groupe Délice — Site Soliman**.

## Version
**V1.5 — Météo automatique, suivi terrain et journal de décision**

## Périmètre
- Site Soliman : CLC, SBC, Delta Plastic, STIAL, Boucharray, Atig
- PCA Inondations détaillé pour CLC
- Checklists simplifiées et modifiables pour les autres entités
- Dashboard DG et cockpit cellule de crise
- Suivi CLC → Boucharray
- Météo automatique pour Soliman et l'amont Oued El Bey
- Données terrain saisies par les équipes
- Preuves photo, journal de décision et brief DG

## Utilisation
Ouvrir `index.html` dans un navigateur moderne.

> Important : les données météo automatiques constituent une aide à la décision. La vigilance officielle et les observations terrain restent à vérifier séparément.

## Versioning
Cette branche contient la version applicative V1.5 au 18 septembre 2026.
